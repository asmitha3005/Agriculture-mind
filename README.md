# AgriMind AI 🌱

An AI-powered agriculture assistant that helps users
understand visible plant and leaf symptoms.

## Features

- AI-based plant image assessment
- Gemini Vision integration
- Plant health observations
- General treatment guidance
- Prevention recommendations
- AI agriculture chatbot
- Camera image assessment
- Responsive interface

## Technologies

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript

## Installation

Install dependencies:

pip install -r requirements.txt

Set environment variables:

GEMINI_API_KEY=your_api_key
FLASK_SECRET_KEY=your_secret_key

Run the application:

python app.py

## Deployment

The application can be deployed using Render.

Build command:

pip install -r requirements.txt

Start command:

gunicorn app:app

## Important Disclaimer

AgriMind AI provides preliminary visual guidance.
It is not a scientifically validated disease diagnosis
system or a substitute for agricultural expert advice.

Image-based assessments may be inaccurate.
